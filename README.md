### A. TNEWS 数据获取与预处理

#### 1. 环境要求

- Python 3
- jieba 中文分词库

安装依赖：

```bash
python -m pip install jieba
```

#### 2. 数据集准备

本项目使用 CLUE 提供的 TNEWS 中文新闻分类数据集。

下载地址：https://storage.googleapis.com/cluebenchmark/tasks/tnews_public.zip

解压后，将数据文件放入：

```text
data/raw/TNEWS/
```

需要包含：

- train.json
- dev.json
- test.json
- labels.json

#### 3. 预处理流程

A 部分主要完成以下工作：

1. 读取并检查 TNEWS 数据集。
2. 统计训练集各新闻类别的数量及占比。
3. 使用 jieba 对中文新闻文本进行分词。
4. 仅使用训练集构建词表。
5. 将词语转换为数字编号，设置 `<PAD>` 和 `<UNK>`。
6. 将原始新闻类别标签映射为 0～14 的连续编号。
7. 对文本序列进行填充和截断，当前最大长度设置为 50。
8. 分别处理训练集、验证集和测试集。
以下是更为详细的A部分（可以便于后续理解）：

####

本项目使用 TNEWS 中文新闻分类数据集。为了使原始新闻文本能够被 RCNN 模型读取和处理，需要对数据进行统一的预处理。具体步骤如下：

**（1）读取并检查 TNEWS 数据集**

首先，读取 TNEWS 数据集中的训练集（train.json）、验证集（dev.json）和测试集（test.json）。

通过 Python 程序逐行读取 JSON 格式的数据，并检查每条数据的内容结构是否完整，重点检查新闻文本字段、类别标签以及测试集中的样本 ID。

其中，训练集和验证集包含新闻文本及对应的类别标签，而测试集不包含真实类别标签，但保留每条新闻对应的 ID，以便后续模型预测结果与原始新闻进行对应。

通过数据检查，确认数据能够被正常读取，为后续预处理工作做好准备。

**（2）统计训练集各新闻类别的数量及占比**

为了了解 TNEWS 数据集的类别分布情况，对训练集中的新闻类别进行统计。

程序根据每条新闻的原始标签（label），计算各类别所包含的样本数量，并进一步计算每个类别占训练集总样本数的比例。

通过统计可以了解不同新闻类别之间的样本分布是否均衡，为后续模型训练和分类效果分析提供参考。

本项目共包含 15 个新闻分类类别。统计结果显示，不同类别的样本数量存在一定差异，其中科技类新闻数量较多，股票类新闻数量较少，说明数据集存在一定的类别不均衡现象。

**（3）使用 jieba 对中文新闻文本进行分词**

原始新闻文本是连续的中文句子，计算机不能直接按照单词的方式理解其结构，因此需要先进行中文分词。

本项目使用 jieba 中文分词工具，将每条新闻文本切分为一个个独立的词语。

例如：

原始文本：

```text
苹果发布新款手机
```

分词后：

```text
苹果 / 发布 / 新款 / 手机
```

经过分词处理后，原本连续的新闻文本就被转换成了由多个词语组成的序列，为后续词表构建和数字化处理提供基础。

**（4）仅使用训练集构建词表**

完成中文分词后，需要建立一个词表，用于记录数据集中出现过的词语，并为每个词语分配一个唯一的数字编号。

本项目只使用训练集中的新闻文本构建词表，不使用验证集和测试集中的文本参与词表构建。

这样可以避免在模型训练前利用验证集和测试集的信息，保证数据处理过程更加规范。

此外，在词表中设置两个特殊标记：

- `<PAD>`：填充标记，编号为 0。当新闻文本分词后的长度不足规定长度时，使用该标记补齐。
- `<UNK>`：未知词标记，编号为 1。当验证集或测试集中出现词表中没有的词语时，使用该标记代替。

通过这种方式，建立词语与数字编号之间的对应关系，为后续文本数字化处理做好准备。

**（5）将词语转换为数字编号**

计算机模型不能直接将中文词语作为输入，因此需要将分词后的每个词语转换为对应的数字编号。

程序根据前面建立的词表，查找每个词语对应的编号，并按照原来的词语顺序组成数字序列。

例如，假设某条新闻经过分词后得到：

```text
苹果 / 发布 / 新款 / 手机
```

经过词表查询后，可能转换为：

```text
[125, 36, 87, 214]
```

这里的数字仅用于说明转换过程，实际编号以项目生成的 `vocab.json` 为准。

如果某个词语不在词表中，则使用 `<UNK>` 对应的编号 1 代替。

经过这一步处理，新闻文本就从中文词语序列转换成了模型可以使用的数字序列。

**（6）将原始新闻类别标签映射为连续编号**

TNEWS 数据集原本使用 100、101、102 等数字表示不同的新闻类别，但这些原始标签并不是从 0 开始连续排列的。

为了方便后续模型进行多分类任务，需要将原始标签重新映射为从 0 到 14 的连续编号。

例如：

| 原始标签 | 模型使用的编号 |
|---|---:|
| 100 | 0 |
| 101 | 1 |
| 102 | 2 |
| 103 | 3 |
| …… | …… |
| 116 | 14 |

本项目根据 `labels.json` 中提供的类别顺序建立标签映射关系，并保存为两个文件：

- `label2id.json`：记录原始标签到模型编号的对应关系。
- `id2label.json`：记录模型编号对应的原始标签及类别名称。

这样既方便模型训练时使用连续数字表示类别，也便于后续将模型预测的类别编号还原为对应的新闻类别。

**（7）对文本序列进行填充和截断**

由于不同新闻文本经过分词和数字化处理后，得到的数字序列长度并不相同，而模型通常需要统一输入序列的长度，因此需要进行填充和截断处理。

本项目将最大文本长度暂定为 50。

具体处理方式如下：

- 当数字序列长度不足 50 时，在序列末尾使用编号为 0 的 `<PAD>` 标记进行补齐。
- 当数字序列长度超过 50 时，保留前 50 个词语对应的数字编号，截去超出部分。

例如：

原始序列：

```text
[12, 25, 38, 41]
```

填充后：

```text
[12, 25, 38, 41, 0, 0, ..., 0]
```

最终序列长度为 50。

通过对原始文本长度进行统计发现，训练集和验证集中超过 50 个词的新闻数量都极少，测试集中没有超过 50 个词的新闻。因此，当前将最大长度设置为 50，能够保留绝大多数新闻文本的完整信息。

**（8）分别处理训练集、验证集和测试集**

完成前面的各项准备工作后，使用统一的预处理流程分别处理训练集、验证集和测试集。

三个数据集均需要经过中文分词、词表转换以及序列填充和截断，最终得到长度统一的数字序列。

对于训练集和验证集，还需要将原始新闻类别标签转换为连续编号，以便后续模型训练和验证。

对于测试集，由于原始数据不包含真实类别标签，因此只进行文本处理，并保留原始样本 ID，不额外生成虚假的类别标签。

最终，三个数据集分别保存为 JSONL 格式文件：

- `train.jsonl`：处理后的训练集，包含文本数字序列及类别标签。
- `dev.jsonl`：处理后的验证集，包含文本数字序列及类别标签。
- `test.jsonl`：处理后的测试集，包含文本数字序列及原始样本 ID。

经过以上步骤，原始 TNEWS 中文新闻数据被转换为格式统一、长度一致的数字化数据，为后续 RCNN 新闻分类模型的训练、验证和预测提供输入数据。





#### 4. 运行方法

在项目根目录打开终端，依次运行：

```bash
python A_data_preprocessing/load_data.py
python A_data_preprocessing/data_analysis.py
python A_data_preprocessing/build_vocab.py
python A_data_preprocessing/preprocess.py
python A_data_preprocessing/check_processed.py
```

#### 5. 输出文件

处理后的文件保存在：

```text
data/processed/
```

主要包括：

- vocab.json：词表
- label2id.json：原始标签到连续编号的映射
- id2label.json：连续编号到原始标签信息的映射
- train.jsonl：处理后的训练集
- dev.jsonl：处理后的验证集
- test.jsonl：处理后的测试集

#### 6. 数据规模

| 数据集 | 样本数量 |
|---|---:|
| 训练集 | 53,360 |
| 验证集 | 10,000 |
| 测试集 | 10,000 |
| 合计 | 73,360 |

共有 15 个新闻分类类别。

当前文本最大长度设置为 50，所有处理后文本均统一为长度 50 的数字序列。

注意：测试集不包含真实分类标签，预处理时保留原始样本 ID，供后续预测结果对应使用。
